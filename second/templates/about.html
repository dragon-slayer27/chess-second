How Second works

A language model on its own is bad at chess. It will happily explain a move that is illegal, or tell a ten-year-old they lost their queen when they lost a pawn. So in Second the model never analyses anything. It only puts verified facts into kind words.

  1. Stockfish checks every move. Each position is analysed (two best lines, depth {{ settings.engine_depth }}). A move counts as a mistake when the player's winning chances drop by 10 or more percentage points, or 15 or more for a blunder, using the same curve and thresholds as Lichess.
  2. Code turns the analysis into facts. python-chess finds what actually happened: a piece left undefended, a fork, a missed checkmate, a back-rank mate, material won or lost along the engine's line.
  3. Gemma writes the notes. An open-weight Gemma model gets only those facts and writes a headline, an explanation, a question to ask the student, a rule of thumb, homework and a note for parents in their language.
  4. The verifier checks every claim. Every move, square, "mate in N", move number and "you lose your X" in the note must appear in the facts. If not, Gemma gets the list of problems and tries again. After three failed tries Second uses a plain note built from the facts, so nothing invented ever reaches a student.

Why open models

  • Private by default. Run locally, students' games and names never leave the coach's laptop. The model doesn't even see the name: Second fills it in afterwards.
  • Free to run. No per-review API bill, so a coach can review 30 games every Sunday at no cost.
  • Swappable. The same prompts and verifier work with Gemma on this laptop, on Ollama Cloud or on Google AI Studio.
  • Built on open chess. Stockfish (GPL), python-chess (GPL) and the CC0 Lichess database make this possible.
